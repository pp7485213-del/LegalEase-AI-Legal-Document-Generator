# LegalEase: AI-Powered Legal Document Generator

## 📌 Project Overview

LegalEase is an AI-powered legal document generation system designed to help users create legal documents easily and efficiently.

The system simplifies the document creation process by collecting the required information from the user and generating a structured legal document based on the selected document type.

## 🎯 Objectives

- Simplify the process of creating legal documents.
- Reduce the time required for manual document preparation.
- Provide an easy-to-use interface for users.
- Generate structured legal documents based on user requirements.
- Improve accessibility to basic legal document generation.

## 🚀 Key Features

- User-friendly interface
- Legal document type selection
- User information collection
- AI-powered document generation
- Structured document output
- Document preview and download
